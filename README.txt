# بوت الاخوه 24/7 - جاهز لـ Railway

## كيف ترفعه مجانا (دقيقتين):
1. ادخل railway.app وسجل دخولك بـ GitHub
2. اضغط New Project > Deploy from GitHub repo (ارفع هذا المجلد لقithub)
3. في Variables حط:
   DISCORD_TOKEN = توكن بوتك
4. في Settings > Start Command خليه:
   python bot.py
5. Railway بينزل FFmpeg تلقائيا - لو ما نزله، ضيف في Dockerfile
